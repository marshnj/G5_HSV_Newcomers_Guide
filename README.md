# G5_HSV_Newcomers_Guide
Huntsville Newcomers Guide App

Project Description and Features

The App is designed to be a Guide to Huntsville that a person moving to the city for the first time
could download themselves or be given by their new employer.  It has 10 screens:

Home
Apartments
Entertainment
Government Offices
Hotels
Museums
Parks
Real Estate Companies
Restaurants
Sign up for Newsletter

The home screen explains the purpose of the Guide and lists links to each screen.

Each page allows the user to return to the Home Screen.

The Apartments Guide screen lists and provides links to websites for seven popular apartment complexes
and to a comprehensive Apartment guide.  

The Entertainment Guide screen lists and provides links to websites for seven popular entertainments
including a, bar, comedy club, pool, pool hall, etc. and a link to a website with a comprehensive list 
of entertainments that is updated regularly.  

The Government Offices screen provides links to the DMV, voting registrar, utilities, and a city and county
website with a complete list of government services.

The Hotels screen links to seven popular hotels and a link to a complete hotel listing for temporary housing for newcomers.

The Museums screen links to seven popular museums and a link to a museum list from TripAdvisor.

The Parks screen links to 7 parks and a link to a complete Huntsville parks and recreation list of parks.

The Real Estate Companies screen links to 7 realtors and real estate companies and a link to a complete list of Huntsville Realtors & Real Estate Agents.

The Restaurants screen links to 7 popular restaurants and to a website with a complete link of restaurants that allows you to search by cuisines.

The Newsletter screen lets the user enter their first and last names, e-mail address, and phone number.

Appropriate music for each screen is played softly while on that screen. The music ends when you go to a website.

Once you have used a linked website, use "back" to return to the last app screen.

Setup Instructions

To install this App, download the pre-built APK from the releases section.

1. Go to the [G5_HSV_Newcomers_Guide](https://github.com/marshnj/G5_HSV_Newcomers_Guide) GitHub repository on the Android device on which you want to install the App.

2. Navigate to the repository's releases page: Go to the GitHub repository and look for a "Releases" tab or link. 

3. Locate the APK: Find the latest release that includes the APK file. 

4. Download the APK: Click on the APK file link to download it to your device.
 
5. Install the APK: On your Android device, you may need to enable "Install from unknown sources" in your settings     
   and then install the downloaded APK.
